# Crypton — Collaborative Git & Front-End Practice

A small collaborative HTML/CSS website project used to practice Git teamwork and building pages together.

## Project

The **Crypton** interface features a trading-themed landing page, a navigation bar, promotional sections, graphics, and supporting pages.

## Files

- **home.html:** main landing page.
- **about.html:** informational content.
- **contact.html:** a placeholder page in the current repository.
- **style.css:** site styling.
- **img/**: images and graphical assets.

## Technologies

HTML5, CSS3, Font Awesome, and Google Fonts.

## Preview

Open **home.html** in your browser.

## Notes

Some navigation targets in the markup are not present in this snapshot of the repository. This is a front-end/Git exercise, not a production trading platform.
